Six rules every
component follows

These decide most design arguments before they start.

Code for repeatable work. AI for judgement.

Scheduling, running, storing and retrying are plain code. A model is called only when a decision needs reading and reasoning.

Every AI output is typed and checked.

Workers return a fixed schema with a confidence score and evidence links. Free text never drives an action.

People get cards, not chats.

Every human question is a one-click card in the inbox, with the evidence already attached.

Tests belong to the customer.

Generated tests are plain Playwright, Appium and k6 files. If Proofline disappears, the tests still run.

Nothing runs without a budget.

Each change and each project has a hard AI spend cap. Work stops at the cap and reports what it has.

Read-only by default.

Write actions (tickets, pull requests, merges) need an explicit policy. Production is never written to.

Anatomy of a worker

Every worker is defined by the same six fields. This is the Triager, the first one we build.

InputOne failure cluster: error, screenshot text, HTTP log, backend trace, PR diff, run history
ToolsRead artifacts, query history, read the diff. Read-only.
ModelMedium. Escalates to large only when confidence is low.
BudgetHard cap per cluster, counted against the change's budget
Outputverdict · confidence 0 to 1 · evidence links · next action
Checked byGolden failure set in CI. Every human answer becomes a new case.

How a failure
gets its verdict

The heart of the product. Three questions, asked in order, from cheapest to most expensive.

Signals it reads

Error textScreenshot textHTTP statusRate-limit headersBackend traceTiming vs historyFiles in the diffSandbox healthOther tests in the run

Example: "Rate limit exceeded" + HTTP 429 + 0 requests left = environment, without a single model call.

Confidence above the project's threshold

Proofline acts. At trust level L2 the action is a proposal you approve; at L3 it acts and tells you after.

Confidence below it

A "bug or intended?" card goes to the inbox, with the evidence. Your answer becomes a new test case for the Triager.

Gate to phase 1

Evals in CI

Every prompt or model change reruns the golden set. A drop blocks the merge.

Shadow mode

New workers log what they would do, without doing it, until they agree with people.
