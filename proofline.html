Scope and the 90% definition

What 90% means

  • Metric: Human Minutes per Release (HMR), measured per project before and after.
  • Applies to repeatable QA work: planning, writing, environments, data, running, triage, maintenance, reporting.
  • Exploratory testing stays human-led and AI-assisted. It is reported separately, never hidden inside the 90%.
  • Humans keep four touchpoints: grant access, confirm intent, bug or intended, go/no-go.

Non-goals

  • Not a device farm. We integrate with farms rather than rebuild them.
  • Not a screenshot crawler as the main engine. Exploration is budgeted and human-seeded.
  • No write actions against production. Production mode is read-only.
  • Not a replacement for user research. Usability judgement stays with people.

Cost control

  • AI runs once per change, never per click
  • Smallest model that can do the job, large only for judgement
  • Per-project budgets with hard caps, caching of repeated context
  • Findings stream out as they happen, so a stopped job still pays

Quality control

  • Eval harness scores the AI's own triage against human labels
  • A different model reviews every test the writer produces
  • Silent self-healing is banned: unsure means ask
  • Every AI decision is logged with its evidence

Core data model

Workspace

  • Organisation → Projects → Environments → Builds
  • App Model: Screens, States, Endpoints, Entities, Roles, Flows
  • Intent: approved behaviour, linked to a Requirement
  • Test asset: code file in git, linked to Intents

Runs

  • Run → Step results → Artifacts (video, trace, HAR, logs)
  • Failure → Cluster (root cause) → Verdict (product, test, environment)
  • Approval: the four human touchpoints, with who and when
  • Ticket, Budget, Audit event

Security, privacy and deployment

Protection

  • Tenant isolation at the database row level
  • Test logins live in a vault and reach the AI only as a handle, never as a value
  • PII redacted before any model call
  • Content from the app under test is data, never instructions
  • No destructive actions against production
  • Full audit log of every AI and human decision

Deployment

  • SaaS: fastest start
  • Hybrid: cloud brain, runner inside the client network
  • Self-hosted: for regulated clients
  • SSO, SAML, SCIM, role-based access
  • Data residency, bring-your-own model key
  • SOC 2 Type II track
